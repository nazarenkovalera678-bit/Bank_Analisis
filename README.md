# Bank_Customer_Churn_Analysis

# 🏦 Аналіз відтоку клієнтів банку (Bank Customer Churn Analysis)

## 📌 Мета проєкту

Метою проєкту є аналіз причин відтоку клієнтів банку та виявлення факторів, які найбільше впливають на рішення клієнтів припинити користування банківськими послугами.

На основі отриманих результатів будуть сформульовані висновки та рекомендації, які допоможуть банку зменшити рівень відтоку клієнтів і підвищити їхню лояльність.

---

## 📊 Бізнес-проблема

Банк спостерігає зниження доходів від своїх послуг. Однією з можливих причин є відтік клієнтів, однак керівництво не має достатньої інформації про масштаби проблеми та характеристики клієнтів, які залишають банк.

У межах цього проєкту буде проведено аналіз клієнтських даних, щоб:

* визначити частку клієнтів, які припинили користуватися послугами банку;
* виявити основні фактори, пов'язані з відтоком;
* порівняти поведінку клієнтів, які залишилися, із тими, хто пішов;
* підготувати практичні рекомендації для зменшення рівня відтоку.
